## 元数据、未知值和历史

保存 `source_id + source_notice_id` 稳定键、规范化高校原文URL、标题、高校发布日期、首次发现、最近观察、详情最近观察、企业标题线索、批次原文、原文明示届别/毕业窗口、截止原句与可明确解释的日期、内容哈希和观察事件。

- `university_published_on` 为高校列表的发布/转载日期；不是雇主首次发布日期。`employer_published_on` 保持未知。南开详情另有学校日期时单独保留，冲突明确显示。
- `first_seen_at` / `last_seen_at` 是系统观察的UTC时间，界面按设备本地时区显示；学校日历日期直接保留，不进行UTC转换。
- 只有原文明确的“2027届”等进入 `explicit_cohorts`；“2027年校招”不会变成2027届。毕业窗口原句单独保存，不推断用户届别。
- `company_hint` 只是标题提取线索，未核验雇主主体。学校“代发”标签不会误当公司。`batch_text` 保留标题中的招聘批次文字，不做跨校或跨年批次合并。
- 截止只有完整年/月/日、明确申请截止语境、单一无歧义日期且未被截断时才能解析。`10月31日`、区间、多日期、统计进度、待定/预计等均保持 `unknown`。原句可见；日期值没有自动补时区，也不推断“招聘中/已截止”。最终应核对雇主原文。
- `campus_restriction` 和 `availability` 均未知；公开网页不代表对所有学校开放。
- 只保存短摘要（最多220字符）、必要短证据与链接，不保存整篇HTML/原文或联系方式。script/style/iframe等不参与文本；联系方式段落跳过。附件仅标记未解析，不下载PDF、OCR或调用模型。
- 解析正文最多100,000字符；截断明确标记，截止保持未知。详情读取失败时保留此前结果，并展示最近失败与原来的详情观察时间。
- 内容或元数据变化保存前后差异、哈希和观察事件；普通再次观察也有记录。失败、空解析、未出现在本页均不会清空历史或假定下线。

## API

所有API沿用现有Host、Origin、Sec-Fetch-Site和匿名会话保护；POST还要求同源Origin、CSRF和写入速率限制。先通过现有 `GET /api/state` 建立会话。新API不扩大跨站导航豁免。

- `GET /api/notices`：读取共享公开缓存，不访问高校。按学校日期倒序返回最多200条、总数、每校状态/读取范围和最近10个实际刷新运行。
- `POST /api/notices/refresh`：JSON `{}` 刷新两校，或 `{"sources":["nankai","dlut_panjin"]}` 选择已接入来源。拒绝其他键、任意URL、未知/重复来源。响应包含最新缓存及本轮 `run`；部分失败也保留成功记录和明确失败。
- `GET /api/notices/{source_id}:{notice_id}/events`：最多100条倒序观察事件；UI展示最近12条。

来源状态包括从未刷新、成功、部分成功、失败、冷却和暂停。范围说明包括列表页数/上限、列表条数、详情页数、学校日期范围、未读取后续页和错误原因。200表示已处理请求，不等于每个高校或详情成功。

## 请求与安全边界

- 固定两个HTTPS主机及robots/list/已审核数字详情路径。请求不接受用户URL；拒绝端口、凭据、查询参数、fragment、任意路径和重定向。学校列表链接只允许同源已知路径，规范化后再验证；不跟随雇主站、微信、附件或登录链接。
- 无Cookie、认证头、浏览器会话或用户资料。网络在固定 `-I -S` 隔离子进程中执行，空环境、96MiB地址空间、CPU/文件句柄上限和自终止计时器；父进程实施每请求7秒硬时限并终止回收超时子进程。
- 来源读取/解析总预算35秒、最多10次请求；每校有公平时间预算，请求间至少1秒。HTTP响应最多768KiB，HTML节点/深度和文本解析有界。存储/WSGI处理另有短SQLite锁超时，因此35秒是来源工作预算，不是无条件端到端SLA。
- 直接HTTPS使用已验证公网IP连接，TLS仍验证原主机，防DNS重绑定。若维护者已配置进程HTTPS代理，只传递该代理配置，DNS/网络出口信任转移至维护者代理；网页/API无法选择代理。
- robots每24小时重新检查。规则禁止即暂停；未支持的crawl-delay/request-rate转维护者复核，不自行忽略。robots404/410只表示未发现规则，不视为无限采集或转载许可。
- 401/403持久暂停，进程重启不会自动重试；429尊重完整Retry-After且至少等待本地冷却。无登录、CAPTCHA、反检测或封锁绕行。恢复暂停需维护者先复核许可/站点状态。
- 共享刷新锁和SQLite短租约避免并发重复读取；清理失败仍释放进程锁，租约可过期。请求取消不触发第二次刷新。

2026-10-11普通公开读取复核中两校列表/详情返回200，robots返回404；所检查页面链接中没有发现明确使用条款入口，大工页有版权声明。这不是站点整体法律审查或自动采集许可。仅做低频、有界读取与最小元数据/短证据展示；如出现明确站点限制，应暂停并复核。来源观察见 [证据JSON](evidence/university-source-observations-20261011.json)。

## 数据库与部署

新增 `<APPLYPILOT_DATA_DIR>/university-notices.sqlite3`，仅包含 `un_notices`、`un_events`、`un_sources`、`un_runs`、`un_lease`。这是共享公开数据缓存，不存档案或个人会话数据。不改现有session/profile/application库，不修改旧 `user_version` 或运行旧库数据迁移。初始化采用幂等 `CREATE IF NOT EXISTS`，只在使用本功能时创建，故新增缓存故障不妨碍原工作台启动。

最大数据库32MiB、4,000条公告、20,000条观察和2,000次实际刷新运行。到阈值时停止新增工作并提示维护者，不自动删除不可恢复的历史。暂无清理/归档管理接口；长期使用需安排经过备份和用户确认的维护。每次部署先备份数据目录，增量替换代码并重启现有App即可；无新依赖、端口、服务、凭据或基础设施。回滚代码不需要删除新增数据库，也不会碰原库。
